# Lorne Gross Corporate Lawyer: Homepage

Static front page (HTML and CSS only, no build step) for Lorne Gross Corporate Lawyer, 100 King St W, Suite 5600, Toronto.

## Structure
```
index.html        the page
css/style.css     animations and mobile rules
images/           photos (see images/README.md for file names and sizes)
.nojekyll         tells GitHub Pages to serve the files as they are
```

## Publish with GitHub Pages
1. Create a repository on GitHub and upload everything in this folder (keep the folder structure).
2. Go to **Settings > Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then **Save**.
3. The site goes live at `https://<username>.github.io/<repo>/` after a minute or two.

## Notes
- The location is a live Google Maps embed (100 King St W, Suite 5600, Toronto).
- Photos: add them to `images/`. Until then the page shows its illustrations.
- Contact form is design only; connect it to a form service (Formspree, Netlify Forms, etc.).
- Fonts load from Google Fonts (Playfair Display, Inter).
